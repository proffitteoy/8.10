# 问题 2：CP-SAT 直接求解结果

## 模型

在死区比例 0.15 的正方形轮廓内，确定各 HardBlock 的整数左下角坐标和 90° 旋转状态，满足不重叠、不越界，并最小化总 HPWL：

\[
\min \sum_k\left[
\max_{p\in N_k}X_p-\min_{p\in N_k}X_p+
\max_{p\in N_k}Y_p-\min_{p\in N_k}Y_p
\right].
\]

实现将中心坐标统一乘 2，从而精确表示半整数模块中心。轮廓真实边长为 `sqrt(1.15A)`，整数坐标边界使用 `floor(L)`，不会因向上取整增加额外死区。
