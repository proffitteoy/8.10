第二问可以看成第一问的一个非常自然的“固定轮廓 + 换目标函数”版本。你第一问现在的模型是旋转变量 + 坐标 + 不重叠，并优化 (W,H) 和面积；第二问不需要推翻它。仓库当前的问题 1 基线本身也是这个结构。

按仓库当前统一口径，第二问是：死区比例固定为 (0.15)，芯片轮廓为正方形，在不重叠、不越界条件下最小化总 HPWL；HardBlock 的引脚取模块几何中心，Terminal 坐标固定。

设有 (n) 个模块。模块 (i) 原始尺寸为

[
(w_i,h_i),
]

旋转变量

[
r_i\in{0,1}.
]

旋转后的宽高写成

[
\tilde w_i=(1-r_i)w_i+r_i h_i,
]

[
\tilde h_i=(1-r_i)h_i+r_i w_i.
]

设左下角坐标为

[
(x_i,y_i).
]

模块总面积是常数

[
A_0=\sum_{i=1}^n w_i h_i.
]

按仓库当前死区定义 (\rho=0.15)，正方形芯片面积为

[
A_{\mathrm{chip}}=(1+\rho)A_0=1.15A_0,
]

因此边长固定为

[
\boxed{
L=\sqrt{1.15\sum_{i=1}^n w_i h_i}
}
]

这一步和第一问差别很大：现在已经没有 (W,H) 需要优化了，直接固定

[
W=H=L.
]

然后是边界约束：

[
0\le x_i,\qquad
0\le y_i,
]

[
\boxed{
x_i+\tilde w_i\le L,\qquad
y_i+\tilde h_i\le L.
}
]

对于任意两个不同模块 (i,j)，至少满足四种相对位置中的一种：

[
\boxed{
x_i+\tilde w_i\le x_j
;\lor;
x_j+\tilde w_j\le x_i
;\lor;
y_i+\tilde h_i\le y_j
;\lor;
y_j+\tilde h_j\le y_i
}
]

这就是第一问已有的 NoOverlap 结构，基本可以原封不动保留。

真正新增的是线网目标。

对于模块 (i)，题目规定它的引脚位于模块几何中心，因此：

[
X_i=x_i+\frac{\tilde w_i}{2},
\qquad
Y_i=y_i+\frac{\tilde h_i}{2}.
]

Terminal (t) 的位置不是变量，而是附件 `.pl` 给出的常数：

[
(X_t,Y_t)=(X_t^{\mathrm{fix}},Y_t^{\mathrm{fix}}).
]

假设第 (k) 条线网包含的全部节点集合为 (N_k)，那么这一条网的 HPWL（Half-Perimeter Wirelength）就是

[
\boxed{
\operatorname{HPWL}_k
=====================

\left(
\max_{p\in N_k}X_p-\min_{p\in N_k}X_p
\right)
+
\left(
\max_{p\in N_k}Y_p-\min_{p\in N_k}Y_p
\right)
}
]

所以第二问整个问题最终可以压成一句：

[
\boxed{
\min_{x_i,y_i,r_i}
\sum_{k=1}^{m}
\left[
\max_{p\in N_k}X_p-\min_{p\in N_k}X_p
+
\max_{p\in N_k}Y_p-\min_{p\in N_k}Y_p
\right]
}
]

满足

[
r_i\in{0,1},
]

[
\tilde w_i=(1-r_i)w_i+r_i h_i,
\qquad
\tilde h_i=(1-r_i)h_i+r_i w_i,
]

[
0\le x_i,\quad
0\le y_i,
]

[
x_i+\tilde w_i\le L,
\qquad
y_i+\tilde h_i\le L,
]

以及所有模块两两不重叠。

也就是说，第一问到第二问实际上就是：

[
\boxed{
\text{Q1: }\min WH
\quad\longrightarrow\quad
\text{Q2: }\min \sum_k \operatorname{HPWL}_k
}
]

同时把

[
W,H\quad\text{变量}
]

改成

[
\boxed{W=H=L=\sqrt{1.15A_0}}
]

固定常数。

还有一个你后面写 CP-SAT 时非常值得直接采用的技巧。因为模块中心有

[
x_i+\frac{\tilde w_i}{2},
]

会出现半整数，不要引入浮点数，直接把全部引脚坐标乘 (2)：

[
\boxed{
\hat X_i=2x_i+\tilde w_i,\qquad
\hat Y_i=2y_i+\tilde h_i.
}
]

Terminal 则写成

[
\hat X_t=2X_t,\qquad
\hat Y_t=2Y_t.
]

于是每条网定义

[
\hat X_k^{\max}=\max_{p\in N_k}\hat X_p,
\qquad
\hat X_k^{\min}=\min_{p\in N_k}\hat X_p,
]

[
\hat Y_k^{\max}=\max_{p\in N_k}\hat Y_p,
\qquad
\hat Y_k^{\min}=\min_{p\in N_k}\hat Y_p.
]

目标直接变成整数：

[
\boxed{
\min
\sum_{k=1}^{m}
\left[
\hat X_k^{\max}-\hat X_k^{\min}
+
\hat Y_k^{\max}-\hat Y_k^{\min}
\right]
}
]

它其实是原始 HPWL 的两倍：

[
\operatorname{HPWL}_{\mathrm{real}}
===================================

\frac12\operatorname{HPWL}_{2}.
]

因为乘 (2) 不改变最优解，所以完全可以让 CP-SAT 优化这个整数目标。

我认为第二问最核心的数学结构其实就这三个框：

[
\boxed{L=\sqrt{1.15\sum_iw_ih_i}}
]

[
\boxed{\text{Boundary}+\text{NoOverlap}}
]

[
\boxed{
\min\sum_k
[
(\max X-\min X)+(\max Y-\min Y)
]
}
]

所以它并不需要先上模拟退火。你第一问那个直接优化模型完全可以继续扩展：**删掉面积目标，固定正方形边界，再给每个 net 加四个极值变量，目标改成总 HPWL。** 这就是我建议第二问首先实现的精确数学基线。
