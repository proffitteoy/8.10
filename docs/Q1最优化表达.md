对，先把第一问当作一个纯粹的最优化问题，不讨论任何算法。

题目第一问只要求：矩形模块允许旋转、彼此不能重叠；芯片轮廓不固定；第一优先级最小化轮廓面积，面积相同时再使长宽比尽量接近 (1)。

设共有 (n) 个 HardBlock。`.blocks` 文件给出每个模块的矩形尺寸。

设第 (i) 个矩形原始宽高为

[
(a_i,b_i),\qquad i=1,\dots,n.
]

定义旋转变量

[
r_i\in{0,1},
]

其中 (r_i=0) 表示不旋转，(r_i=1) 表示旋转 (90^\circ)。于是实际宽高为

[
w_i=(1-r_i)a_i+r_i b_i,
]

[
h_i=(1-r_i)b_i+r_i a_i.
]

再令

[
(x_i,y_i)
]

为第 (i) 个矩形左下角坐标。

芯片外包矩形的宽、高记为

[
W,\qquad H.
]

那么第一问最干净的数学模型就是：

[
\boxed{
\min_{\mathrm{lex}}
\left(
WH,;
\rho(W,H)
\right)
}
]

其中

[
\rho(W,H)
=========

\max\left{
\frac WH,\frac HW
\right}.
]

这里 (\rho\ge1)，且

[
\rho=1\iff W=H.
]

所以它准确表达“面积相同时，越接近正方形越好”。

“lex” 是字典序优化，即：

[
\boxed{\text{先严格最小化 }WH,\quad
\text{再在面积最优解中最小化 }\rho.}
]

这比写

[
WH+\lambda\rho
]

严谨，因为题目并没有允许拿面积换长宽比。

---

约束首先是所有模块都必须处于包围矩形内：

[
x_i\ge0,\qquad y_i\ge0,
]

[
x_i+w_i\le W,
]

[
y_i+h_i\le H,
\qquad i=1,\dots,n.
]

然后是核心的“不重叠”。

对于任意

[
1\le i<j\le n,
]

两个矩形至少满足以下四种空间关系之一：

[
\boxed{
x_i+w_i\le x_j
\quad\lor\quad
x_j+w_j\le x_i
\quad\lor\quad
y_i+h_i\le y_j
\quad\lor\quad
y_j+h_j\le y_i
}
]

分别表示：

[
i\text{ 在 }j\text{ 左边},
]

[
i\text{ 在 }j\text{ 右边},
]

[
i\text{ 在 }j\text{ 下边},
]

[
i\text{ 在 }j\text{ 上边}.
]

所以第一问完整的抽象模型其实只有：

[
\boxed{
\begin{aligned}
\min_{\mathrm{lex}}\quad
&\left(
WH,;
\max\left{\frac WH,\frac HW\right}
\right)\
\mathrm{s.t.}\quad
&x_i\ge0,\quad y_i\ge0,\
&x_i+w_i\le W,\qquad i=1,\dots,n,\
&y_i+h_i\le H,\qquad i=1,\dots,n,\
&
x_i+w_i\le x_j
;\lor;
x_j+w_j\le x_i\
&\qquad\lor;
y_i+h_i\le y_j
;\lor;
y_j+h_j\le y_i,
\qquad i<j,\
&w_i=(1-r_i)a_i+r_i b_i,\
&h_i=(1-r_i)b_i+r_i a_i,\
&r_i\in{0,1}.
\end{aligned}
}
]

这已经是第一问完整、精确的数学定义。

如果要把它直接交给 Gurobi/SCIP 之类的优化器，还需要把那个“(\lor)”改成整数约束。对每对 (i,j) 引入

[
L_{ij},R_{ij},B_{ij},T_{ij}\in{0,1},
]

分别表示左、右、下、上。

要求至少选一种：

[
L_{ij}+R_{ij}+B_{ij}+T_{ij}\ge1.
]

然后用一个充分大的常数 (M)：

[
x_i+w_i
\le
x_j+M(1-L_{ij}),
]

[
x_j+w_j
\le
x_i+M(1-R_{ij}),
]

[
y_i+h_i
\le
y_j+M(1-B_{ij}),
]

[
y_j+h_j
\le
y_i+M(1-T_{ij}).
]

例如当

[
L_{ij}=1
]

时，第一条就变成真正的约束

[
x_i+w_i\le x_j.
]

当

[
L_{ij}=0
]

时，

[
x_i+w_i\le x_j+M
]

基本不起作用。

因此得到一个标准的混合整数非线性规划：

[
\boxed{\text{MINLP}}
]

它的非线性主要只有一个：

[
WH.
]

事实上，第一问现在真正值得讨论的问题就变成了：

[
\boxed{\text{这个 MINLP 能不能进一步转成 MILP / CP 模型直接求？}}
]

而不是先讨论模拟退火。

我下一步建议就从这里继续：**研究怎样把 (WH) 这个乘积目标处理掉，把整个第一问变成尽可能标准的精确优化模型。**这一步决定我们到底有没有必要碰启发式算法。
