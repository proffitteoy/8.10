# 问题 1：直接优化基线实验

## 1. 题目实际要求

问题 1 要求对 `n100`、`n200`、`n300` 分别给出合法模块摆放、芯片轮廓面积、长宽比和可视化结果。题目没有指定算法，也没有要求证明全局最优。

因此本实验的定位是：先验证“不引入 B\*-Tree/Fast-SA，只把数学模型交给通用求解器”能否在正式规模上给出有用结果。

## 2. 直接模型

实现采用 OR-Tools CP-SAT：

- 每个模块使用一个布尔旋转变量；
- 坐标、宽高和轮廓宽高使用整数变量；
- 使用二维全局不重叠约束 `NoOverlap2D`；
- `W`、`H` 分别等于所有模块右边界、上边界的最大值；
- 使用乘法等式 `A = W × H`；
- 利用整体旋转对称性增加 `W ≥ H`，不损失可行解；
- 第一阶段最小化面积；第二阶段固定第一阶段找到的面积，再最小化 `W-H`。

固定面积且 `W ≥ H` 时，最小化 `W-H` 与使长宽比更接近 1 一致。只有第一阶段被证明为 `OPTIMAL`，才能声称面积全局最优；否则结果只称限时可行解。

求解前使用确定性的多目标宽度货架布局生成初始可行解。结果输出后，再由不依赖 CP-SAT 的代码逐一检查旋转尺寸、非负坐标、轮廓边界、最小外包矩形和全部模块对不重叠。

## 4. 如何解释结果

直接模型已经完成题目要求的基本闭环：三组数据都有合法位置、面积、长宽比、完整 JSON 和可视化。因此，“第一问先用简单直接优化求解”是可行的，可以保留为基线。

但它还不适合作为最终高质量算法的唯一依据：

1. 100 个模块时也无法在几十秒内证明面积最优，扩大到 200/300 后下界没有实质推进；
2. 第二阶段在短时限内没有找到同面积下更均衡的因子与布局，当前结果呈单排式极扁轮廓；
3. 题目虽然只在面积相同时比较长宽比，但论文展示若只给出极端长宽比，仍需要解释严格字典序目标带来的现象；
4. 当前面积仍比模块总面积高约 10%–11%，是否足够好需要与至少一个轻量布局改进方法对照。

## 5. 当前决策

暂不直接引入完整 B\*-Tree/Fast-SA。先把本直接模型作为可复算基线；下一步若要提高答案质量，优先增加轻量的构造布局与局部改进，并使用同一套面积、长宽比和可行性检查进行公平比较。只有当轻量方法无法明显改善面积或稳定性时，再引入领域标准算法。

这种安排符合题目要求：数学模型保持精确，数值结果如实标记为限时可行解，不额外承担题目没有要求的全局最优证明成本。
