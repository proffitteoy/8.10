第四问其实比第三问更干净。它不是要你重新搞一个“高级优化算法”，而是要求把第一问的“矩形模块布局模型”推广成“非规则正交多边形布局模型”。题面也明确说算法可以在问题 1 基础上修改，不要求重新设计。

我建议把第四问设计成：

> 矩形模型 → L/T 型模块的矩形分解 → 旋转状态离散化 → 分块非重叠约束 → 沿用第一问精确搜索/剪枝 → 用面积下界证明图 3 解是全局最优。

核心很漂亮，而且图 3 这个例子实际上可以做到“零死区”。

### 1. 最关键的模型修改：把非规则块拆成矩形块

不要直接搞复杂的多边形相交公式。

把每个模块 (B_i) 表示成若干个互不重叠的小矩形的并：

[
B_i=\bigcup_{k=1}^{m_i}B_{ik}.
]

例如图 3 中：

* (b_1)：T 型，可拆成 (4\times2) 的横矩形和 (2\times2) 的竖矩形；
* (b_2)：L 型，可拆成若干矩形；
* (b_3)：(2\times1)；
* (b_4)：(1\times4)。

这样，第一问原来“矩形与矩形不能重叠”的约束根本不用推翻，只需要从

[
B_i\cap B_j=\varnothing
]

扩展为

[
B_{ip}\cap B_{jq}=\varnothing,
\qquad
\forall p,q.
]

也就是：两个异形模块不重叠，当且仅当组成它们的任意两个基本矩形都不重叠。

这是第四问最值得写的数学处理。

---

### 2. 旋转从二状态改为四状态

第一问规则矩形其实只有

[
r_i\in{0,1}
]

对应 (0^\circ,90^\circ)，因为 (180^\circ) 和 (0^\circ) 对矩形没有区别。

现在统一定义

[
r_i\in{0,1,2,3},
]

分别表示

[
0^\circ,\quad90^\circ,\quad180^\circ,\quad270^\circ.
]

对于异形模块，四个方向可能确实不同。

实现时不要在优化过程中计算三角函数，直接预生成

[
\mathcal S_i=
\left{
S_i^{(0)},S_i^{(1)},S_i^{(2)},S_i^{(3)}
\right}.
]

每个 (S_i^{(r)}) 保存这一方向下所有组成矩形的相对坐标。

所以一个模块的决策变量还是很简单：

[
(x_i,y_i,r_i).
]

---

### 3. 非重叠约束怎么写

设模块 (i) 的第 (p) 个组成矩形，在旋转 (r_i) 后的局部范围为

[
[a_{ip}^{(r_i)},b_{ip}^{(r_i)}]
\times
[c_{ip}^{(r_i)},d_{ip}^{(r_i)}].
]

摆放到 ((x_i,y_i)) 后就是

[
[x_i+a_{ip}^{(r_i)},,x_i+b_{ip}^{(r_i)}]
\times
[y_i+c_{ip}^{(r_i)},,y_i+d_{ip}^{(r_i)}].
]

对于模块 (i,j) 的任意基本矩形 (p,q)，至少满足四种空间关系之一：

[
x_i+b_{ip}^{(r_i)}
\le
x_j+a_{jq}^{(r_j)},
]

或

[
x_j+b_{jq}^{(r_j)}
\le
x_i+a_{ip}^{(r_i)},
]

或

[
y_i+d_{ip}^{(r_i)}
\le
y_j+c_{jq}^{(r_j)},
]

或

[
y_j+d_{jq}^{(r_j)}
\le
y_i+c_{ip}^{(r_i)}.
]

这就是第一问矩形 disjunctive constraint 的自然推广。

论文里这一组公式基本就是第四问的核心数学表达。

---

### 4. 目标函数几乎不用改

题目仍然要求最小包围轮廓面积。

定义

[
W=
\max_{i,p}
\left(
x_i+b_{ip}^{(r_i)}
\right),
]

[
H=
\max_{i,p}
\left(
y_i+d_{ip}^{(r_i)}
\right).
]

于是

[
\boxed{
\min A=WH
}
]

即可。

如果你想严格继承第一问“面积相同时长宽比越接近 1 越好”的规则，可以做字典序优化：

[
\min
\left(
WH,,
\left|\frac WH-1\right|
\right).
]

第一问本身就是“面积优先、长宽比次优”的要求。

---

### 5. 算法根本不用换

这也是我认为第四问不要塞模拟退火、遗传算法之类东西的原因。

你第一问如果已经是“候选旋转 + 精确摆放 + 剪枝”，第四问只改三个模块：

[
\boxed{
\text{orientation generation}
+
\text{collision detection}
+
\text{bounding box calculation}
}
]

原来的

[
\text{rectangle overlap}
]

替换成

[
\text{component-rectangle overlap}.
]

剪枝仍然能用：

[
A_{\mathrm{LB}}
\ge
\sum_i \operatorname{Area}(B_i).
]

而且这次图 3 只有四个模块，独立旋转状态实际上也很少：

[
4\times4\times2\times2=64
]

个不同的有效方向组合。

所以用精确搜索反而特别合适。

---

## 6. 图 3 这个验证题其实有一个非常漂亮的结论

从图中尺寸可得：

[
S_{b_1}=4\times2+2\times2=12,
]

[
S_{b_2}=6,
]

[
S_{b_3}=2,
]

[
S_{b_4}=4.
]

因此所有模块的总面积为

[
S_{\mathrm{total}}
==================

# 12+6+2+4

24.

]

任何芯片轮廓显然满足

[
\boxed{WH\ge24}.
]

而这四个模块恰好能够无缝拼成一个

[
\boxed{4\times6}
]

的矩形。

也就是说存在布局满足

[
WH=24.
]

结合面积下界：

[
WH\ge24
]

便立刻得到

[
\boxed{A_{\min}=24}.
]

这不是“算法搜出来一个 24，看起来不错”，而是：

[
\underbrace{A\ge24}*{\text{理论下界}}
\qquad+\qquad
\underbrace{A=24\text{ 的可行构造}}*{\text{算法得到}}
]

从而严格证明

[
\boxed{A^*=24}.
]

这个证明质量比单纯报优化器结果高很多。

具体拼法可以理解成：

```text
┌───────────────┐
│     b1 横梁    │
│               │
├───┐       ┌───┤
│b2 │ b1柄  │b4 │
│   │       │   │
│   ├───┬───┤   │
│   │   │b3 │   │
└───┴───┴───┴───┘
```

更准确地按单位网格表示，(4\times6)：

```text
b1 b1 b1 b1
b1 b1 b1 b1
b2 b1 b1 b4
b2 b1 b1 b4
b2 b2 b3 b4
b2 b2 b3 b4
```

这里 (b_2) 正好是 L 型，(b_1) 正好是 T 型，因此 24 个单位面积全部填满，没有任何空洞。

---

所以第四问的论文逻辑我建议直接定成：

[
\boxed{
\text{正交异形模块}
\rightarrow
\text{矩形分解}
\rightarrow
\text{四方向离散旋转}
\rightarrow
\text{分块非重叠约束}
\rightarrow
\text{沿用Q1精确搜索}
\rightarrow
A_{\min}=24
}
]

我认为这是第四问最合适的处理。它的亮点不应该是“再上一个智能算法”，而应该是“第一问模型具有可扩展性”：**只修改几何表示与碰撞约束，优化框架本身保持不变**。这正好回应题目“讨论问题1模型如何修正”的要求。
