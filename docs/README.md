## 维护规则

1. 每个问题优先保留一份“当前实验/实现说明”和一份“完整建模/算法说明”。
2. 被替代的方案必须在标题或开头标注“历史基线”，不得与当前默认方案并列而不说明状态。
3. 论文可引用的数值必须指向可复算的 `solution.json`，并同时记录数据集、算法、参数、随机种子和可行性结论。
4. 新实验先写入独立目录；确认代表性结果后再更新结果清单，不直接覆盖仍被文档引用的旧结果。
5. 工具生成的 Skills 索引不进入仓库文档，也不作为算法依据。
